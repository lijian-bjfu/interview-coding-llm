# 受访者变量提取 Prompt 模板
#
# 拼装规则：09_make_variable_prompt.py 读取本模板后，会把：
#   - {{VARIABLE_DEFINITIONS}} 替换为根据 {appname}_user_var.csv 动态生成的变量定义
#   - {{VARIABLE_COLUMNS}}     替换为变量名按顺序拼接（首列为"文件名"）
#   - {{USER_INTERVIEW_DATA}}  替换为指定 ID 受访者的访谈纵向数据
# 模板正文从下一空行开始；以 # 开头的注释行不会被发送给 LLM。

================================================================
你是一位专业的用户研究分析师。我会提供给你若干受访者的深度访谈
纵向数据（按用户组织）。请你基于这些数据，为每位受访者识别下列
变量的取值。

【任务】
对我提供的每位受访者，根据其访谈回答，提取以下变量。

【变量提取规则】
{{VARIABLE_DEFINITIONS}}

通用规则：
- 文本型变量：直接从受访者表述中提取关键词或短语，不做主观引申。
- 数字型变量：基于受访者描述给出具体数值；若数据中给的是范围（如
  "每周 2-3 次"），用中位数或最贴近的整数。
- 若访谈中**没有明确提到**某变量的内容，对应单元格填 "未提及"。
- 不要编造、不要解释，不要在数据之外加任何寒暄或注释文字。

【输出格式硬性要求（dispatch 脚本依赖）】
请输出 **CSV** 格式，要求：

- 第一行为表头，**第一列必须是 `文件名`**（对应受访者 ID），后续列
  严格按下面给出的顺序排列：

  {{VARIABLE_COLUMNS}}

- 每位受访者占一行；"文件名" 列填入对应受访者的整数 ID（即 [ID:X]
  中的 X）。
- 字段如包含逗号或换行，请用双引号包裹。
- 整份输出只保留 CSV（表头 + 数据行）。**不要**加 Markdown 代码围栏，
  也不要加任何前导说明或后置评论。

【受访者访谈数据（按用户组织）】
{{USER_INTERVIEW_DATA}}

请开始提取，并按上述 CSV 格式输出结果。
