# 精炼编码本 Prompt 模板（每个大纲分类用一次）
#
# 拼装规则：07_make_codebook_prompt.py 读取本模板后，会把：
#   - {{CATEGORY}}          替换为目标大纲分类名
#   - {{RAW_CODEBOOK_CSV}}  替换为该分类的 raw_codebook_{category}.csv 完整内容
# 模板正文从下一空行开始；以 # 开头的注释行不会被发送给 LLM。

================================================================
你是一位资深的定性研究方法论专家。我已经基于开放式编码（inductive
coding）汇总了若干访谈问题的初步编码（raw codebook），现在需要你
协助我把这些初步编码**自下而上**地重构为结构清晰、定义精准、操作
可执行的精炼编码本（refined / deductive codebook）。

【目标 (Objective)】
将原始 raw codebook 重构为一个层级结构清晰、各编码间意义互斥、
信息全覆盖、且每个编码都附带详细应用规则的方法论编码本，使后续
研究者能够基于该编码本对全部数据进行一致的演绎编码。

【现有 raw codebook 的字段含义】
- code_name：编码名称
- definition：编码概念定义
- theme：基于访谈问题层面的初步主题
- source_question：该编码来自哪个访谈问题
- frequency_in_question：该编码在该问题数据中的出现次数
- representative_quotes：该编码的典型引文

【核心理念】
请把原始字段视为"语境数据"，从编码本身的语义出发自下而上重新
聚类，不要被原 theme 字段束缚。

【指导原则】
1. **语义互斥原则**：最终编码本中每个 Code_Name 必须代表一个独立、
   不与他人重叠的概念。
2. **信息全覆盖原则**：必须覆盖原编码所揭示的全部现象。
   - 低频编码（frequency_in_question < 3）优先并入更宏观的父级编码。
   - 实在独特又无法归类的，单独放入"其他"编码并说明。
3. **跨编码语义复用**：同一个旧编码可被多个新编码合并使用。建立新
   编码时，要扫描整个 raw codebook，即便某旧编码已被使用过，只要它
   在某个侧面反映新编码语义，仍可再次合并。
4. **操作明确原则**：每个编码必须配备详尽的 Application_Rules，包括
   纳入标准、排除标准，以及与相邻编码的边界判定。

【建议的引导过程（你可以按此节奏与研究者协作）】
- 步骤一：宏观理解。先通读整份 raw codebook，告诉研究者你观察到的
  显著主题倾向、潜在聚类与可疑低频项。
- 步骤二：聚焦主题。围绕某一研究者指定或你判断重要的主题先做局部
  重构，注意以问题、引文、原 theme 作为语境理解每条编码的真实含义。
- 步骤三：深入或矫正。研究者会反馈，你据此深入挖掘或重新聚焦。
- 步骤四：确认结果。把当前主题的精炼编码以下文输出格式整理出来。
- 步骤五：下一主题。重复二/三/四，强调对已用编码的复用。
- 步骤六：第一次优化（合并相似编码、补全要素）。
- 步骤七：完善编码（与 raw codebook 对照，找出尚未覆盖的内容）。

【最终输出格式（硬性要求，dispatch 脚本依赖）】
请将最终精炼编码本以 **CSV** 格式输出。要求：

- **第一行必须是 CSV 注释行**（**不要去掉 # 号**，整行照抄但替换 category）：

  # category={{CATEGORY}}

- **第二行起为 CSV 表头**，列名严格使用：

  Theme,Code_Name,Merged_Original_Codes,Total_Original_Frequency,Definition,Application_Rules

- 每列含义：
  - Theme：二次抽象的高阶概念性主题。
  - Code_Name：精炼后的新编码名（≤4 个中文字）。
  - Merged_Original_Codes：被合并到该编码下的原始编码名称列表，
    使用形如 "[原编码1, 原编码2, ...]" 的字符串。
  - Total_Original_Frequency：被合并的原始编码频次之和（整数）。
  - Definition：对新编码核心概念的全面、精确的文字定义。
  - Application_Rules：详细的应用规则，**必须包含三部分**：
    1) 纳入标准；
    2) 排除标准；
    3) 边界案例（当与另一编码意义重叠时如何判定）。

- 全程使用中文。CSV 各字段如包含逗号或换行，请用双引号包裹。
- 整份输出只保留：第一行 # category=... 注释行 + 第二行表头 +
  数据行。**不要**在 CSV 之外加任何寒暄、解释或 Markdown 代码围栏。
